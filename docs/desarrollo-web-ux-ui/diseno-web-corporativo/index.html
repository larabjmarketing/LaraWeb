Preguntas frecuentes

¿Cuánto tarda en hacerse una web corporativa?

Depende del número de páginas, del contenido disponible y de las revisiones. Tras entender el alcance te doy un plazo cerrado.

¿La web incluye SEO?

Incluye el SEO técnico de base: estructura, velocidad, metadatos y datos estructurados. El posicionamiento continuo (contenidos y enlaces) es un trabajo posterior que se puede contratar aparte.

¿Puedo editar yo los contenidos?

Sí. La web se entrega con un sistema de gestión de contenidos acorde a tu caso y con una sesión de formación.
