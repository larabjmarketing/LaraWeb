Preguntas frecuentes

¿Qué diferencia hay entre UX y UI?

UX (experiencia de usuario) es cómo funciona y se siente el producto: estructura, flujos y facilidad de uso. UI (interfaz de usuario) es cómo se ve: colores, tipografía, componentes y estilo visual. Ambas se trabajan juntas.

¿Se trabaja en Figma?

Sí. Los prototipos y el sistema de diseño se entregan en Figma y quedan en tu cuenta.

¿Hace falta prototipar antes de desarrollar?

Es muy recomendable en proyectos complejos: cambiar un prototipo cuesta mucho menos que cambiar código.
